## 文件

- `article.pdf`：完整图文 PDF，A4 分页，保留图注、表格、公式、附录和参考文献；不是摘要或翻译。
- `article.md`：完整英文 Markdown；图片使用相邻 `assets/` 内的本地文件，公式保留原始 TeX。Markdown 阅读器的排版与公式支持可能不同。
- `index.html`：基于原网站样式的离线 HTML；数学公式预渲染为内联 SVG，无脚本、无网络依赖。请保留 `assets/`。
- `source.html`：下载时的原始 HTML，仅供溯源；原始页面本身仍引用在线资源。
- `assets/`：18 张原图及下载时使用的样式和 MathJax 运行时；离线 HTML 的样式与公式已内联，不再执行 MathJax。
- `citation.bib`：原文书目信息，供手动导入 Zotero。
- `manifest.json`、`verification.json`：来源、文件哈希与生成校验记录。

PDF 是重新分页的打印版，不承诺与连续网页像素级一致；正文不做改写，已移除站点导航、相关推荐和跟踪脚本。

## 导入 Zotero（尚未执行）

当前项目的 AGENTS.md 限定 Zotero 为只读，本次未向 Zotero 新增或修改条目。

推荐：在 Zotero 中用“文件 → 导入”导入 `citation.bib`，将生成的条目移入“人工智能 / RSI”，再把 `article.pdf` 拖到该条目上作为附件。导入向导如有“将导入条目放入新分类”选项，可取消勾选。也可直接把 PDF 拖入 RSI，但网页文章的作者、标题和日期可能需要手动补齐。
