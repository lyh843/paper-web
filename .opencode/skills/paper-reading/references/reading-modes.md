# Reading depth and optional lenses

Depth controls how much of the paper is read. Lens controls emphasis beyond the default 13 questions, not whether questions 9–13 are answered. Do not combine them into an automatic escalation ladder.

| Request | Depth | Reader-facing result |
|---|---|---|
| “Read this paper”, “仔细阅读”, “make a mind map” | DEEP READ (default) | One visual, interactive HTML: orientation → problem/value and prior gap → plausible idea route → intuition → worked method → accessible mathematics → question-driven evidence → takeaways → fragile assumption → one-week reproduction → counterexample → searched subsequent research → substantive follow-up idea |
| “What is this about?”, “worth reading?” | SCAN | Provisional global map, principal result, relevance if context exists |
| “Review / find weaknesses / do claims hold?” | DEEP READ + REVIEW | All 13 questions, with an expanded evidence and fairness audit |
| “Compare with my work / reproduce / next experiments” | DEEP READ + RESEARCH | All 13 questions, with tailored comparison, implementation detail, or an optional research card |

A user-supplied paper and a request to read it are sufficient intent for DEEP READ, including the user's default scrutiny and research questions. Do not invent a personal research project or relevance threshold. A proposed follow-up and reproduction plan do not authorize actually running experiments or modifying external data. Ask only if a missing choice would materially change the deliverable and cannot be inferred. Honor explicit requests to narrow scope.

## Passes

1. **Orientation:** title, abstract, introduction, central figures, conclusion, major results. Draft a provisional map.
2. **Reconstruction:** read the full relevant method/argument and experiments, including figure captions, table notes, definitions, and key appendix material. Revise the map wherever the source contradicts it.
3. **Explanation:** apply [narrative-logic](narrative-logic.md), drafting and checking the explanatory prose spine before visual layout. Connect the exact problem and prior gap to a qualified idea reconstruction, actual intuition, worked method, accessible mathematics, question-driven evidence, and takeaways. Connect diagram elements and meaningful offline interaction to this narrative and original source locations.
4. **Mandatory research extension:** apply [research-extension](research-extension.md) to diagnose the fragile assumption, plan a one-week test, construct a fair counterexample, actually search and verify subsequent literature, and propose a substantive follow-up with a targeted novelty check. Expand or tailor this work according to any explicit REVIEW/RESEARCH lens.

SCAN can end after orientation. Default DEEP READ completes reconstruction, explanation, and research extension even if the reader did not give an external goal. Report unavailable search or source access instead of claiming all checks are complete. A paper can be interesting without being relevant to an active project.
